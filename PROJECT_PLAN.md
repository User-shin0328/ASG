## Known plan deviations to close before v0.1

- The plan's PostgreSQL runtime and migrations are implemented. All plan-defined F01-F06 cases and bounded cross-process race scenarios have evidence; extended production-capacity qualification remains outside the local measurements.
- Implementation is standard-library Python rather than FastAPI/Pydantic/Streamlit; the HTTP contract and browser dashboard are intentionally lightweight in this reference cut.
- Declarative policy uses JSON-compatible YAML and the Python standard library; this keeps policy parsing dependency-free while remaining valid YAML 1.2.
- The Compose stack has agent, admin, tool, and PostgreSQL/data networks plus a host-facing dashboard network. A local model service is not included.
- Docker Desktop needs a host-facing bridge for dashboard port forwarding. Dashboard startup now applies an nftables default-drop output chain before binding, allows only loopback, established replies, embedded DNS, and the resolved Gateway IPv4:8000, then drops all capabilities before running as UID 10003. D01 verified the tested IPv4 TCP path and restart behavior; it does not claim complete protocol coverage or protection from host/Docker administrators.
