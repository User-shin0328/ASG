## Known plan deviations to close before v0.1

- The plan's PostgreSQL runtime and migrations are implemented. Targeted F01-F06 cases now have evidence; extended cross-process stress remains outstanding.
- Implementation is standard-library Python rather than FastAPI/Pydantic/Streamlit; the HTTP contract and browser dashboard are intentionally lightweight in this reference cut.
- Declarative policy uses JSON-compatible YAML and the Python standard library; this keeps policy parsing dependency-free while remaining valid YAML 1.2.
- The Compose stack has agent, admin, tool, and PostgreSQL/data networks plus a host-facing dashboard network. A local model service is not included.
- The dashboard's host-facing network permits outbound connections from that container. An internal-only Docker network blocked egress but also prevented Windows host access to the published dashboard port, so that experiment was reverted. Gateway, agent, and tool sandbox remain on internal networks. Local N01-N06 checks cover the agent boundary and do not claim dashboard egress isolation.
