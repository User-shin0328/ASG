# Local acceptance assessment

**Assessment date:** 2026-10-02

**Result:** Local v1.0 acceptance is **not passed**.
**Scope:** Evidence gathered in the local Windows/Docker Desktop exercise. This is not a production certification. The user's explicit hold on GitHub publication remains in force.

## Decision

The core Gateway boundary, approval integrity, idempotency, audit controls, container isolation checks, recovery cases, dashboard JSON download and approval-button click, bounded resource soak, preregistered L01-L04 matrix, tracked-history scan, full image filesystem scan, six local demos, clean-checkout reproduction, runtime log probe, and real-model one-turn stop test have evidence. Rules scanner v2 measured 42% recall / 4% FPR on a fresh synthetic v6 set, below the 80% recall target; a v5 run reached 80% / 10% only after that set was used to tune and is diagnostic, not held-out evidence. The optional semantic prefilter met the numeric target on author-created synthetic v4/v5/v6 sets (v6 86% recall / 0% FPR) and is integrated into the host-run Agent adapter as a fail-closed auxiliary check; it never grants permissions. These sets are not independent benchmarks. A real local model run on the assigned adversarial fixture had its text withheld; the Gateway denied the model's report action. The four-arm study used only in-memory tools; baseline attacks all succeeded in that relaxed mock, while policy-only and full had no simulated attack success. All 68 cases are mapped in `docs/case-traceability.md`, with partial and open cases clearly identified. A real browser approval click now has evidence; the approved action reached only the fictional mock outbox and replay returned the same receipt. Execution policy remains the security boundary.
