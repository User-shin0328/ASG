# Local acceptance assessment

**Assessment date:** 2026-10-02

**Result:** Local v1.0 acceptance is **not passed**.
**Scope:** Evidence gathered in the local Windows/Docker Desktop exercise. This is not a production certification. The user's explicit hold on GitHub publication remains in force.

## Decision

The core Gateway boundary, approval integrity, idempotency, audit controls, container isolation checks, recovery cases, dashboard JSON download and approval-button click, bounded resource soaks, preregistered L01-L04 matrix, tracked-history scan, full image filesystem scan, six local demos, clean-checkout reproduction, runtime log probe, and real-model one-turn stop test have evidence. A newly frozen, author-created v7 holdout measured 86% Qwen semantic recall and 0% FPR (43/50 attacks, 0/50 controls, no inference errors, p95 1.0794s), meeting the plan's initial numeric target on that set. The same set produced 36% recall / 26% FPR for rules v2. The v7 set is a single authored synthetic holdout and does not establish external generalization. Rules v2 measured 42% / 4% on v6; the v5 run reached 80% / 10% after that set had been used to tune and is diagnostic only. The v6 semantic results (86% prior prompt, 88% current prompt) are repeatability results on previously observed data. The context-aware prompt diagnostic measured 75.6% recall / 0% paired-control FPR on InjecAgent base. Its related enhanced-setting run measured 100% / 0%, but its locally generated controls remove the enhanced setting's fixed hacking prefix while attack cases retain it; the wrapper cue invalidates that score as evidence of generalization or acceptance. The classifier is auxiliary and never grants permissions. A real local model run on the assigned adversarial fixture had its text withheld; the Gateway denied the model's report action. The four-arm study used only in-memory tools; baseline attacks all succeeded in that relaxed mock, while policy-only and full had no simulated attack success. All 68 cases are mapped in `docs/case-traceability.md`, with R04/R05 partial because public docs and remote CI depend on the GitHub hold. A real browser approval click now has evidence; the approved action reached only the fictional mock outbox and replay returned the same receipt. Execution policy remains the security boundary.
