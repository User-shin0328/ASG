# Local acceptance assessment

**Assessment date:** 2026-10-06

**Result:** Local v1.0 acceptance is **not passed**.
**Scope:** Evidence gathered in the local Windows/Docker Desktop exercise. This is not a production certification. The user has placed GitHub publication on hold; no remote, public repository, push, or release exists.

## Decision

The core Gateway boundary, approval integrity, idempotency, audit controls, container isolation checks, recovery cases, dashboard JSON download and approval-button click, bounded resource soaks, preregistered L01-L04 matrix, tracked-history scan, full image filesystem scan, six local demos, clean-checkout reproduction, runtime log probe, and real-model one-turn stop test have evidence. The integrated validation-frozen semantic OR n-gram detector measured 96.75% recall / 9.43% FPR on Agentic 5K validation and 99.64% / 9.06% on the single held-out test run, meeting the plan's initial numeric target on those splits. A replay against retained local semantic decisions preserved the measured Qwen v5/v6/v7 results; this is not a fresh LLM evaluation. The n-gram model alone remains weak on local project corpora, and the v7 semantic-only result (86% recall / 0% FPR) is an author-created synthetic holdout, not broad generalization evidence. Deterministic rules v2 misses local dev/v7 targets; the semantic-only classifier measured 72.1% recall / 3.0% FPR on the external Agentic 5K test split. The context-aware semantic diagnostic measured 75.6% recall / 0% paired-control FPR on InjecAgent base. Its enhanced-setting run measured 100% / 0%, but its locally generated controls omit a fixed prefix present in every attack, invalidating that score as generalization evidence. The classifier is auxiliary and never grants permissions. A new real local hybrid run caught an adversarial report that Qwen labeled benign, withheld its content, and Gateway denied an unregistered destination. The four-arm study used only in-memory tools; baseline attacks all succeeded in that relaxed mock, while policy-only and full had no simulated attack success. All 68 cases are mapped in `docs/case-traceability.md`; local README/runbook reproduction passed for R04, but public URL availability remains pending; R05 remains partial because remote CI awaits repository publication. A real browser approval click has evidence; the approved action reached only the fictional mock outbox and replay returned the same receipt. Execution policy remains the security boundary.
