포함: 현재 소스·설정·마이그레이션·문서, 새 실행파일, 최신 세 종류 결과보고서, 모델 제거 목록, 화면 검토와 최종 캡처, 비밀 값 없는 API/바이너리 관찰값.

제외: `.env`, `.venv`, `testing/.runtime`, 실제 토큰과 DSN, SQLite 원본, Docker 볼륨, 빌드 중간 파일, 검사기의 대량 캡처 폴더. 기존 모델 코드·자산의 과거 Git 이력은 재작성하지 않습니다. 고신뢰 패턴 검사는 정의된 키 형식을 찾는 검사이며 모든 종류의 비밀이 없다는 보증은 아닙니다.

## 검토 후 커밋·푸시하는 순서

다음은 이번 전달에 사용하는 절차입니다. 현재 테스트 시작 안내는 [START_HERE.md](../testing/START_HERE.md)에 있습니다. 저장소 루트에서 사용합니다.

```powershell
git status --short
git diff --cached --stat
git diff --cached --check
git commit -F docs/POLICY_GATEWAY_COMMIT_MESSAGE.txt
git push origin main
```

커밋 전에 원격을 다시 갱신해 다른 변경이 없는지 확인하세요. 충돌이나 원격 갱신이 있으면 변경을 통합하고 필요한 검증을 수행한 뒤 일반 푸시합니다. 강제 푸시는 준비하지 않았습니다. 최신 파일을 수정하면 그 파일을 다시 스테이징하고 실행파일·시험 증거에 영향이 있는지도 확인해야 합니다.
