# 정책 게이트웨이 검증 계획

규칙 전용 코드·실제 SQLite/HTTP·실제 PostgreSQL·독립 실행파일을 구분해 검증합니다.

- 단위/통합: 명시적 자동 정책, 예외 검토, 위반 차단, 권한·요청·정책 변경.
- 범위 승인: 원요청 차감, 범위 확대 거부, 만료·취소·소진·교차 테넌트·무권한 발급 거부.
- 예산: 소량 반복·다중 연결 경쟁, 최대량 예약·실제량 정산, 응답 유실·재시도·만료 후 영수증 대조.
- UI: 승인 방식 표시, 반복 범위 발급·사용량·취소, 대기·감사·작동 점검.
- 성능: 측정한 요청 수·동시성·시간만 기록. 대규모 운영 처리량으로 일반화하지 않음.
- 배포: 실행파일 SHA-256과 실제 실행 검증, 모델 파일·연동 코드 제외, 비밀 정보 제외, Git diff 확인.

기존 모델 평가 결과는 역사적 실험 자료이며 현재 정책 게이트웨이의 합격 근거가 아닙니다.
