# Implementation and verification report

**Status:** Local reference MVP; plan acceptance is not passed. Evidence below is local exercise evidence, not a production certification.

The final local acceptance decision and remaining gates are summarized in [final-local-acceptance.md](final-local-acceptance.md). All 68 planned cases now have explicit status and evidence references in [case traceability](case-traceability.md), but a number remain partial or open. The deterministic regex scanner misses its target; the optional semantic prefilter met numeric targets on synthetic held-out v4 and v5 sets, which are not independent benchmarks. The preregistered four-arm L01-L04 matrix used virtual tools only.

This repository contains an in-progress implementation for a single fictional reporting workflow. It has a policy-checked Gateway, PostgreSQL runtime state, a separate HTTP tool sandbox, deterministic input inspection, a review dashboard, local demo data, and focused unit tests. The plan's completion thresholds have not been assessed.

Known limitations: the deterministic regex scanner measured 10% recall / 8% FPR on v4 and 22% / 10% on the new v5 set. The optional semantic prefilter met numeric targets on two author-created synthetic sets; neither is an independent benchmark. The relaxed matrix arms used only in-memory tools; their policy logic is not the Gateway. PostgreSQL audit controls protect against application-role edits but not a database/host administrator. Local v1.0 acceptance is not passed: L03, public-doc reproduction, remote CI, approval-button UI click, a separate physical machine, and broader acceptance cases remain incomplete or unverified. Full-filesystem image scanning was completed, but mounted volumes and undisclosed secret classes are outside its scope. The dashboard's host-facing network permits outbound connectivity; an internal-only bridge and a no-masquerade bridge failed to block egress while meeting all dashboard access needs and were reverted. GitHub publication remains on hold as requested.
