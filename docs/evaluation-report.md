# Initial implementation report

**Status:** In progress; not a v0.1 or v1.0 completion report. Evidence below is local development evidence, not a production certification.

The final local acceptance decision and remaining gates are summarized in [final-local-acceptance.md](final-local-acceptance.md). The deterministic regex scanner misses its target; the optional semantic prefilter met the target on one synthetic v4 set, and the preregistered four-arm L01-L04 matrix has now run to completion with virtual tools only.

This repository contains an in-progress implementation for a single fictional reporting workflow. It has a policy-checked Gateway, PostgreSQL runtime state, a separate HTTP tool sandbox, deterministic input inspection, a review dashboard, local demo data, and focused unit tests. The plan's completion thresholds have not been assessed.

Known limitations: the deterministic regex scanner is not comprehensive and measured 10% recall / 8% FPR on synthetic held-out v4. The optional semantic prefilter met the numeric target on that author-created set and achieved TP60/FP0/FN0/TN30 on the separate L01-L04 matrix workload, which is not an independent benchmark. The relaxed matrix arms used only in-memory tools; its policy logic is not the Gateway. PostgreSQL audit controls protect against application-role edits but not a database/host administrator; F05 secret/log handling is covered by unit-level checks rather than a production log pipeline. Local v1.0 acceptance remains incomplete because the full planned 68-case mapping, clean-machine and README-only reproduction, local commit/CI parity, and Git-history review remain open. The dashboard's host-facing network permits outbound connectivity, and its egress policy has not been restricted or tested. GitHub publication remains on hold as requested.
