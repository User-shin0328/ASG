# Implementation and verification report

**Status:** Local reference MVP; plan acceptance is not passed. Evidence below is local exercise evidence, not a production certification.

The final local acceptance decision and remaining gates are summarized in [final-local-acceptance.md](final-local-acceptance.md). All 68 planned cases have explicit status and evidence references in [case traceability](case-traceability.md); R04 and R05 remain partial. On newly frozen author-created v7, the optional semantic prefilter met the initial target at 86% recall / 0% FPR, while rules v2 measured 36% / 26%. This is one synthetic holdout and does not establish broad generalization. The validation-frozen external n-gram detector is now integrated as an OR layer with semantic Qwen; combined Agentic 5K validation/test results meet the plan's initial numeric threshold and retained-decision replay preserved measured local v5-v7 semantic results. The n-gram model alone remains weak on project-authored corpora. The InjecAgent base diagnostic remains below target at 75.6%; the preregistered four-arm L01-L04 matrix used virtual tools only.

Two isolated multi-process idempotency runs each sent 100 same-key requests across 32 workers to two Gateway containers. All 200 returned HTTP 200 and produced one action and one receipt per round; the two rounds added two summary artifacts and no outbox entries. A separate 50-key/25-worker workload produced 50 unique action and receipt IDs with exactly 50 summary artifacts. These runs establish bounded same-host race behavior, not long-duration production capacity. See `evaluation/results/multiprocess-idempotency-2026-10-02.json` and `evaluation/results/multiprocess-multikey-2026-10-02.json`.

The development input corpus now meets the plan's 30-normal/30-malicious target with 20 label-pure families and zero exact-text overlap against heldout v1-v7. The original 12-row development file is preserved as `evaluation/datasets/dev-v1-12cases-2026-10-01.jsonl`. Rules v2 measured 4 true positives, 0 false positives, 26 false negatives, and 30 true negatives (13.3% recall / 0% FPR) on the expanded development corpus; the run is development-only. Dataset hash, per-case hashes, and metrics are recorded under `evaluation/results/dev-v2-2026-10-02/`.

An auxiliary run on deepset's public direct-prompt test split (116 rows; 60 malicious, 56 normal; no exact text overlap with local sets) measured rules-v2 recall 0% / FPR 0% and local Qwen semantic recall 23.3% / FPR 1.8%, with no inference errors. This dataset is direct-prompt classification, not the project's indirect-document/tool-outcome task; treat the result as evidence of distribution shift, not as a replacement acceptance benchmark. Only metrics and the Parquet SHA-256 were retained, not the source rows. The Hugging Face repository header lists Apache-2.0 while the dataset metadata lists CC-BY-4.0, which is preserved in the evidence record. See `evaluation/results/deepset-direct-prompt-2026-10-02.json` and the [dataset card](https://huggingface.co/datasets/deepset/prompt-injections).

An additional evaluation used the scenario-isolated test split of the public [Agentic Prompt-Injection 5K dataset](https://huggingface.co/datasets/3nesdeniz/agentic-prompt-injection-5k), pinned to repository revision `e658d94` and licensed CC-BY-4.0. It contains 545 rows (280 malicious, 265 normal), with zero exact normalized-text overlap against local development and held-out sets. On the unchanged local Qwen classifier, recall was 72.1% and FPR 3.0%; rules v2 measured 9.3% / 1.9%. The model had zero inference errors; p95 latency was 1.170s. This is below the 80% recall target and is a text-classification result, not an agent action or Gateway-authorization result. Only a normalized row-manifest hash and aggregate metrics were retained. See `evaluation/results/agentic-prompt-injection-5k-2026-10-02.json` and `evaluation/run_agentic5k_external.py`.

A separate standard-library Bernoulli word/character n-gram candidate was trained on the 3,923-row train split only. A threshold was selected using the 467-row validation split (95.13% recall / 0% FPR), then frozen before one test-split run. Validation Qwen OR n-gram measured TP 298, FP 15, FN 10, TN 144 (96.75% recall / 9.43% FPR); test Qwen OR n-gram measured TP 279, FP 24, FN 1, TN 241 (99.64% / 9.06%), with zero inference errors and Qwen p95 1.175s. The n-gram layer alone scored 99.64% / 6.04% on test, but detected 0/50 malicious items in each local held-out v1-v5 and v7 set, 1/50 in v6, and 3/30 development attacks (0% FPR on those local corpora). Its OR integration preserves the captured Qwen outputs on local v5/v6/v7: 90%/2%, 88%/0%, and 86%/0%, respectively. This combined result justified adding the frozen detector as an optional auxiliary layer without replacing semantic inspection. No exact normalized-text overlap existed across train, validation, test, or local sets. The model is packaged with CC-BY-4.0 attribution, provenance, and an integrity hash; only aggregate metrics and hashes are retained. The local n-gram weakness remains a domain limitation: it should not be run alone. Scripts are `evaluation/train_agentic5k_classifier.py`, `evaluation/select_agentic5k_threshold.py`, `evaluation/evaluate_agentic5k_classifier.py`, `evaluation/evaluate_agentic5k_hybrid.py`, `evaluation/evaluate_agentic5k_local_regression.py`, and `evaluation/evaluate_hybrid_local_regression.py`; results are in `evaluation/results/agentic5k-*`.

Three validation-only prompt addenda were also rejected: v1 92.21%/21.38%, v2 85.06%/15.72%, and v3 78.90%/19.50% recall/FPR. None was tested against the held-out set or integrated. A pinned Apache-2.0 [AgentInjectionBench](https://huggingface.co/datasets/sincpp/AgentInjectionBench) diagnostic included 120 attack responses and no benign cases; rules v2 recalled 15.83%, Qwen 45%, and the n-gram candidate 100%. Since there were no normal rows, it provides no FPR/precision estimate and does not count toward acceptance.

The closely aligned [NetInjectBench paper](https://arxiv.org/abs/2607.10490) describes 130 balanced scenarios, including benign, weak/strong attack, and approved-change cases. Its reproducibility section says the prepared benchmark code and artifacts will be released publicly after acceptance; they were therefore unavailable for this local run. Re-evaluate against those artifacts once the authors release them. The paper's results concern action authorization in its mock environment and are not classifier metrics for this Gateway.

The integrated host-adapter smoke used local Ollama Qwen and the default hybrid configuration. On the assigned normal report, the semantic and n-gram classifiers returned benign and the summary artifact was saved; the model additionally attempted `send_report`, which the Gateway denied with `DESTINATION_NOT_REGISTERED`. On the assigned adversarial report, Qwen returned benign but the n-gram layer returned malicious; deterministic input inspection was also `SUSPICIOUS`, so the document content was withheld. The model created a local summary from the withheld response and again attempted a report action that the Gateway denied. Both attempts had zero external submissions and zero inference errors. The raw report text and tokens are not stored in the result. This shows defense-in-depth on those two fixtures; it does not establish broad LLM reliability. See `evaluation/results/agentic5k-hybrid-host-adapter-smoke-2026-10-02.json`.

On the pinned [InjecAgent benchmark](https://aclanthology.org/2024.findings-acl.624/), the baseline local Qwen classifier without task context processed 1,054 indirect tool responses and 1,054 paired neutral controls. It detected 544/1,054 attacks (51.6% recall), flagged 0/1,054 generated controls (0% FPR), and had zero inference errors; p50 was 0.898s and p95 1.530s. A later prompt iteration supplied the benchmark's user instruction as a separate, read-only task-scope field and detected 797/1,054 attacks (75.6% recall), flagged 0/1,054 generated controls, and had zero errors; p50 was 1.059s and p95 1.739s. This iteration was introduced after observing the split and is diagnostic, not independent acceptance evidence; it still misses the 80% target. The attack responses are official cases; controls were generated locally by replacing only the injected instruction with one neutral sentence and are not an official split. Both runs measure content classification, not end-to-end attack success or Gateway authorization. Only hashes, labels, aggregate metrics, and decisions were retained. The upstream dataset repository identifies its license as MIT; attribution and file hashes are in `evaluation/results/injecagent-indirect-2026-10-02.json` and `evaluation/results/injecagent-task-context-diagnostic-2026-10-02.json`.

The same context-aware classifier was also run on pinned InjecAgent `enhanced` files: it marked all 1,054 malicious responses and none of 1,054 generated controls (100% recall / 0% generated-control FPR, p95 1.764s, zero errors). This is not acceptance evidence: the control generator removes the fixed enhanced hacking prefix while positives retain it, creating a wrapper cue that can distinguish the labels. The setting is correlated with the already observed base cases, and controls are not an official benign split. See `evaluation/results/injecagent-enhanced-context-diagnostic-2026-10-02.json` and the evaluator's prefix-removal tests.

A current-prompt recheck of the 100-row synthetic v6 set measured 44/50 true positives, 0/50 false positives (88% recall / 0% FPR), zero inference errors, and p95 1.0933s. This is a regression/consistency check only: the author-created set was previously observed during earlier prompt iterations, so the numeric target on this run does not establish held-out generalization. Its manifest and aggregate output are in `evaluation/results/llm-classifier-v6-task-context-recheck-2026-10-02/`.

The shared semantic prompt detected 43/50 malicious cases and flagged 0/50 normal cases (86% recall / 0% FPR), with no inference errors and p95 1.0794s. Rules v2 on those same cases detected 18/50 attacks and flagged 13/50 normal cases (36% recall / 26% FPR). v7 comprises 20 label-pure families designed by the project evaluator after earlier results were known; it meets the plan's numeric threshold for this authored holdout but is not an independent external benchmark. The prompt and rules were not changed after this run. Full records: `evaluation/results/llm-classifier-v7-preregistered/` and `evaluation/results/rules-v7-heldout/`.

A separate candidate-prompt iteration reached 55% recall / 1.8% FPR on that already-observed external split and 64% / 0% on the previously viewed synthetic v6. It remained below the 80% recall target, regressed from the existing classifier's 86% v6 diagnostic, and was not integrated. Because the prompt was iterated after observing the external split, these figures are diagnostic only; see `evaluation/results/deepset-prompt-iteration-2026-10-02.json`.

Additional local acceptance evidence now includes a 600-second oversized-input soak (1,015 requests; 508/508 body-size rejections were 413 and 507/507 oversized-argument rejections were 422; Gateway memory ended 0.04 MB below its first sample with a 13.56 MB sampled peak above it) and an isolated two-Gateway 50-key burst (50/50 HTTP 200, 50 unique actions and receipts, 0/0/0→50/0/50 artifact/outbox/receipt counts). It has a policy-checked Gateway, PostgreSQL runtime state, a separate HTTP tool sandbox, deterministic input inspection, a review dashboard, local demo data, and focused unit tests. Project-plan acceptance is not passed: deterministic rules and semantic-only classification miss the target on some independent diagnostics, although the integrated semantic OR n-gram hybrid meets the initial thresholds on Agentic 5K validation/test. R04/R05 remain partial while public documentation and remote CI depend on GitHub publication, which is on hold.
