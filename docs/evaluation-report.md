# Implementation and verification report

**Status:** Local reference MVP; plan acceptance is not passed. Evidence below is local exercise evidence, not a production certification.

The final local acceptance decision and remaining gates are summarized in [final-local-acceptance.md](final-local-acceptance.md). All 68 planned cases now have explicit status and evidence references in [case traceability](case-traceability.md); R04 and R05 remain partial. On newly frozen author-created v7, the optional semantic prefilter met the initial target at 86% recall / 0% FPR, while rules v2 measured 36% / 26%. This is one synthetic holdout and does not establish broad generalization. The InjecAgent base diagnostic remains below target at 75.6%; the preregistered four-arm L01-L04 matrix used virtual tools only.

Two isolated multi-process idempotency runs each sent 100 same-key requests across 32 workers to two Gateway containers. All 200 returned HTTP 200 and produced one action and one receipt per round; the two rounds added two summary artifacts and no outbox entries. A separate 50-key/25-worker workload produced 50 unique action and receipt IDs with exactly 50 summary artifacts. These runs establish bounded same-host race behavior, not long-duration production capacity. See `evaluation/results/multiprocess-idempotency-2026-10-02.json` and `evaluation/results/multiprocess-multikey-2026-10-02.json`.

The development input corpus now meets the plan's 30-normal/30-malicious target with 20 label-pure families and zero exact-text overlap against heldout v1-v7. The original 12-row development file is preserved as `evaluation/datasets/dev-v1-12cases-2026-10-01.jsonl`. Rules v2 measured 4 true positives, 0 false positives, 26 false negatives, and 30 true negatives (13.3% recall / 0% FPR) on the expanded development corpus; the run is development-only. Dataset hash, per-case hashes, and metrics are recorded under `evaluation/results/dev-v2-2026-10-02/`.

An auxiliary run on deepset's public direct-prompt test split (116 rows; 60 malicious, 56 normal; no exact text overlap with local sets) measured rules-v2 recall 0% / FPR 0% and local Qwen semantic recall 23.3% / FPR 1.8%, with no inference errors. This dataset is direct-prompt classification, not the project's indirect-document/tool-outcome task; treat the result as evidence of distribution shift, not as a replacement acceptance benchmark. Only metrics and the Parquet SHA-256 were retained, not the source rows. The Hugging Face repository header lists Apache-2.0 while the dataset metadata lists CC-BY-4.0, which is preserved in the evidence record. See `evaluation/results/deepset-direct-prompt-2026-10-02.json` and the [dataset card](https://huggingface.co/datasets/deepset/prompt-injections).

On the pinned [InjecAgent benchmark](https://aclanthology.org/2024.findings-acl.624/), the baseline local Qwen classifier without task context processed 1,054 indirect tool responses and 1,054 paired neutral controls. It detected 544/1,054 attacks (51.6% recall), flagged 0/1,054 generated controls (0% FPR), and had zero inference errors; p50 was 0.898s and p95 1.530s. A later prompt iteration supplied the benchmark's user instruction as a separate, read-only task-scope field and detected 797/1,054 attacks (75.6% recall), flagged 0/1,054 generated controls, and had zero errors; p50 was 1.059s and p95 1.739s. This iteration was introduced after observing the split and is diagnostic, not independent acceptance evidence; it still misses the 80% target. The attack responses are official cases; controls were generated locally by replacing only the injected instruction with one neutral sentence and are not an official split. Both runs measure content classification, not end-to-end attack success or Gateway authorization. Only hashes, labels, aggregate metrics, and decisions were retained. The upstream dataset repository identifies its license as MIT; attribution and file hashes are in `evaluation/results/injecagent-indirect-2026-10-02.json` and `evaluation/results/injecagent-task-context-diagnostic-2026-10-02.json`.

The same context-aware classifier was also run on pinned InjecAgent `enhanced` files: it marked all 1,054 malicious responses and none of 1,054 generated controls (100% recall / 0% generated-control FPR, p95 1.764s, zero errors). This is not acceptance evidence: the control generator removes the fixed enhanced hacking prefix while positives retain it, creating a wrapper cue that can distinguish the labels. The setting is correlated with the already observed base cases, and controls are not an official benign split. See `evaluation/results/injecagent-enhanced-context-diagnostic-2026-10-02.json` and the evaluator's prefix-removal tests.

A current-prompt recheck of the 100-row synthetic v6 set measured 44/50 true positives, 0/50 false positives (88% recall / 0% FPR), zero inference errors, and p95 1.0933s. This is a regression/consistency check only: the author-created set was previously observed during earlier prompt iterations, so the numeric target on this run does not establish held-out generalization. Its manifest and aggregate output are in `evaluation/results/llm-classifier-v6-task-context-recheck-2026-10-02/`.

To replace the previously observed v6 as the current one-shot synthetic holdout, v7 was frozen before the current Qwen run with a dataset SHA-256 and prompt/model versions in `evaluation/heldout-v7-preregistration.md`. The shared semantic prompt detected 43/50 malicious cases and flagged 0/50 normal cases (86% recall / 0% FPR), with no inference errors and p95 1.0794s. Rules v2 on those same cases detected 18/50 attacks and flagged 13/50 normal cases (36% recall / 26% FPR). v7 comprises 20 label-pure families designed by the project evaluator after earlier results were known; it meets the plan's numeric threshold for this authored holdout but is not an independent external benchmark. The prompt and rules were not changed after this run. Full records: `evaluation/results/llm-classifier-v7-preregistered/` and `evaluation/results/rules-v7-heldout/`.

A separate candidate-prompt iteration reached 55% recall / 1.8% FPR on that already-observed external split and 64% / 0% on the previously viewed synthetic v6. It remained below the 80% recall target, regressed from the existing classifier's 86% v6 diagnostic, and was not integrated. Because the prompt was iterated after observing the external split, these figures are diagnostic only; see `evaluation/results/deepset-prompt-iteration-2026-10-02.json`.

Additional local acceptance evidence now includes a 600-second oversized-input soak (1,015 requests; 508/508 body-size rejections were 413 and 507/507 oversized-argument rejections were 422; Gateway memory ended 0.04 MB below its first sample with a 13.56 MB sampled peak above it) and an isolated two-Gateway 50-key burst (50/50 HTTP 200, 50 unique actions and receipts, 0/0/0→50/0/50 artifact/outbox/receipt counts). These bounded exercises do not qualify production capacity. See `evaluation/results/boundary-soak-10m-2026-10-02.json` and `evaluation/results/multiprocess-multikey-2026-10-02.json`.

This repository is an implemented local reference MVP for a fictional reporting workflow. It has a policy-checked Gateway, PostgreSQL runtime state, a separate HTTP tool sandbox, deterministic input inspection, a review dashboard, local demo data, and focused unit tests. Project-plan acceptance was assessed and is not passed: rules v2 misses its fresh-set recall target, and R04/R05 remain partial while public documentation and remote CI depend on GitHub publication, which is on hold.
