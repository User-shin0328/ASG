# Evaluation model attribution

The runtime model `agentic5k-bernoulli-charword-v1-r95b.json` is a packaged copy of the validation-thresholded artifact under `evaluation/models/`. It is derived only from the train split of [Agentic Prompt-Injection 5K](https://huggingface.co/datasets/3nesdeniz/agentic-prompt-injection-5k), pinned at revision `e658d94`.

Attribution: Enes Deniz, *Agentic Prompt-Injection 5K* (2026), CC BY 4.0.
